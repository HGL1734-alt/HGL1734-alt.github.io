# 58CLIENT website

Fresh responsive rebuild inspired by your 67Client reference screenshot.

## Included
- `index.html` — page content
- `style.css` — responsive layout and styling
- `script.js` — mobile navigation

## Background
The full-screen hero uses a Minecraft Cherry Grove wallpaper hosted at:
https://wallpapers.9minecraft.net/cherry-grove-valley-landscape/

The image is loaded directly from the wallpaper host, so the browser needs internet access.

## Publish with GitHub Pages
Upload `index.html`, `style.css`, `script.js` and this README to the root of your Pages repository. Enable Pages in **Settings → Pages** if needed.

## Before publishing
Replace the temporary download/community destinations with your official links once you have them.
