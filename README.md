# 58Client — GitHub Pages

En färdig, responsiv landningssida för 58Client.

## Publicera på GitHub Pages

1. Skapa ett nytt repository på GitHub, till exempel `58client`.
2. Packa upp ZIP-filen och ladda upp `index.html`, `style.css`, `script.js` och `README.md` till repositoryts rot.
3. Öppna **Settings → Pages**.
4. Under **Build and deployment**, välj **Deploy from a branch**.
5. Välj branchen `main` och mappen `/ (root)`, klicka **Save**.
6. Vänta någon minut. Din sida får en adress i stil med `https://ditt-användarnamn.github.io/58client/`.

## Anpassa sidan

- Ändra texter och sektioner i `index.html`.
- Ändra färger och design högst upp i `style.css` (`--accent`, `--cyan`, `--bg`).
- När klienten har en riktig nedladdning: byt länken på knappen i `#download` till din GitHub Releases- eller annan nedladdningslänk.
- Byt gärna versionsnummer och funktionsbeskrivningar så att de stämmer med den faktiska klienten.

Sidan använder Google Fonts för rubrik- och brödtext. Utan internetanslutning används reservtypsnitt.
